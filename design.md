# OnChain CV — Design System

## Aesthetic
Clean SaaS / Apple Wallet. Minimalist, premium, trust-first.

## Typography
- Display: `Syne` (bold headings)
- Body: `Inter` (clean, readable)
- Weights: 400, 500, 600, 700, 800

## Colors
- Background: `#F5F4F0` (warm off-white)
- Surface: `rgba(255,255,255,0.55)` (frosted glass)
- Border: `rgba(255,255,255,0.6)`
- Text Primary: `#0D0D12`
- Text Muted: `#6B7280`
- Accent: `#7C3AED` (violet — Web3 premium)
- Accent 2: `#06B6D4` (cyan highlight)
- Badge Gold: `#F59E0B`

## Shadows
- Card: `0 8px 32px rgba(0,0,0,0.08), 0 1px 2px rgba(0,0,0,0.04)`
- Glass: `0 4px 30px rgba(0,0,0,0.1)`

## Glass Card
- `backdrop-filter: blur(20px)`
- `background: rgba(255,255,255,0.45)`
- `border: 1px solid rgba(255,255,255,0.6)`
- `border-radius: 24px`

## Motion
- Page load: staggered fade+slide-up (Framer Motion)
- Spinner: smooth rotate
- Slide-up panel: spring animation from bottom

## Layout
- Mobile-first, max-width 420px centered on mobile, 640px on desktop
- Generous vertical padding, tight horizontal margins
